# Velocity Apex — customizable mobile controls

Added a per-device mobile control layout editor.

- Open **Настройки → Раскладка кнопок → Настроить**.
- Drag GAS, BRAKE, left/right arrows and HB anywhere on screen.
- Select a button and change its size from 60% to 160%.
- Save or cancel changes; reset returns the editor to the standard layout.
- Saved layout is stored locally on the current device and is applied to both normal/online races and Free Roam.
- Existing controls remain unchanged until the player saves a custom layout.

Validation: full `npm test` suite passed after the update.
