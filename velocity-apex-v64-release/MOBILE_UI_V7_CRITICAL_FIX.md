# Velocity Apex — Mobile UI V7 Critical Fix

Исправлены два критических бага после Mobile UI V6.

## 1. Одиночная гонка

Причина: мобильный CSS V6 задавал `.menu-screen { display:grid!important; }`, что перекрывало общий класс `.hidden`. Из-за этого игровая логика уже запускала гонку, но главное меню визуально оставалось поверх Canvas.

Исправление:

- добавлено `.menu-screen.hidden { display:none!important; }`;
- добавлен отдельный regression test, который не позволит снова сломать скрытие главного меню;
- одиночная гонка и существующая логика race/start не изменялись.

## 2. Отправка жалобы

Исправление:

- сервер теперь формирует успешный ответ непосредственно из результата INSERT и больше не зависит от повторного чтения строки после сохранения;
- клиент безопасно обрабатывает ответ даже при отсутствии номера обращения;
- после успешной подачи выводится `ЖАЛОБА #... УСПЕШНО ОТПРАВЛЕНА`;
- для вопроса выводится `ВОПРОС #... УСПЕШНО ОТПРАВЛЕН`;
- сообщение об успехе остаётся на экране дольше перед переходом в «Мои обращения».

## Проверка

Полный `npm test` проходит успешно, включая standalone race, mobile UI, администрацию, онлайн, Free Roam, рынок, кланы и Owner Panel.
