# Velocity Apex V27 — iPhone install guide

## Что изменено
- В портретном стартовом экране вместе с просьбой повернуть телефон добавлен заметный блок установки приложения.
- Пользователь видит понятную последовательность: Safari → «Поделиться» → «На экран Домой» → «Добавить».
- Для ссылок, открытых из Telegram/встроенного браузера, отдельно указано открыть страницу в Safari.
- Блок адаптирован под короткие iPhone и безопасные зоны экрана.
- При запуске уже установленного PWA в standalone-режиме инструкция скрывается.
- Версия базового CSS обновлена до `20260918-v27` для сброса кэша Safari.

## Миграции
Новых D1-миграций нет.
