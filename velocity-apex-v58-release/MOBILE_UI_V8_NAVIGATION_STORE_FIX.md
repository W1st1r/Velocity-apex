# Velocity Apex — Mobile UI V8 Navigation + Store Fix

## Что исправлено

- Исправлен повторный вход в «Настройки» после нажатия «Назад» на iPhone. Причина была в синтетическом `click`, который Safari мог отправить уже в кнопку, появившуюся под закрытым окном.
- Все основные переходы магазина/гаража переведены на единый `bindTap` с общей защитой от двойного/«призрачного» тапа.
- Добавлены проверки состояния: настройки нельзя открыть из неподходящего экрана, магазин нельзя закрыть повторно из уже закрытого состояния.
- Настройки из паузы одиночной и онлайн-гонки корректно возвращают пользователя именно в паузу, а не в главное меню.
- Полностью пересобран телефонный layout магазина: landing, личный магазин и гараж теперь ограничены safe-area, имеют стабильную сетку, отдельную прокрутку каталога и не растягивают весь экран.
- Карточки магазина, категории, превью, баланс и кнопки «Назад» адаптированы в первую очередь под landscape iPhone.
- Добавлены `.hidden`-регрессии для магазина/гаража/настроек, чтобы мобильные `display`-правила никогда не могли показать закрытый экран.
- Добавлен regression test `mobile_ui_v8_navigation_store.js`.
- Cache bust обновлён до `mobile8`.

## Обновление

cd /workspaces/Velocity-apex
