# APEX — Presence / Ghost Player Fix

Исправлен баг, при котором игрок мог оставаться в списке сервера после закрытия приложения.

## Что изменено

- Добавлен серверный heartbeat-контроль WebSocket-соединений.
- Клиент считается потерянным, если сервер не получает от него данные **12 секунд**.
- Проверка активных соединений выполняется каждые **3 секунды**, поэтому «зависший» игрок удаляется примерно через **12–15 секунд**.
- Обычное окно переподключения уменьшено с 25 до **15 секунд**.
- Сервер теперь удаляет ghost-сессию даже в ситуации, когда платформа не прислала событие закрытия WebSocket после принудительного закрытия приложения.
- Логика применяется и к свободному режиму APEX CITY, и к обычным Online-комнатам.
- Старые зависшие записи очищаются при ближайшем heartbeat sweep после обновления сервера.

## Проверка

Добавлен `tests/presence_timeout_test.mjs`, проверяющий:

- удаление соединения с просроченным heartbeat;
- сохранение активного игрока;
- удаление ghost-игрока без живого WebSocket;
- интервалы timeout/sweep/reconnect grace.

Полный набор тестов проекта `npm test` проходит успешно.
