# Velocity Apex — MEDIA V50

## Что добавлено

- отдельная роль **MEDIA (уровень 5.5)** для официальных контент-мейкеров без наследования модераторских прав;
- префикс MEDIA в Online / Free Roam / чатах и над автомобилями;
- **MEDIA EVENT** в Online → Rooms → Create;
- события на базе существующих Mini Football, Hot Potato, Checkpoint Rush, Drift Battle, King of the Hill и Drag;
- отдельные комнаты по коду / открытые / по приглашённым никам;
- READY + ручной START организатором;
- режим организатора **SPECTATOR**: общий вид, предыдущий/следующий игрок, скрытие HUD;
- серверный призовой фонд: деньги резервируются с личного баланса MEDIA и выплачиваются только после серверного результата;
- идемпотентная защита от повторной выплаты, отмена до старта с возвратом приза;
- дневные лимиты количества событий и суммы наград;
- OWNER PANEL → MEDIA: назначение/снятие роли, блокировка событий, изменение лимитов, статистика;
- Logs → MEDIA EVENTS;
- история MEDIA Events и MEDIA Center;
- D1 migration `0016_media_events.sql`;
- отдельный тест `tests/media_v50_test.mjs`.

## Деплой

Используйте `deploy_velocity_apex_media_v50.sh`. Скрипт распакует релиз во временную папку, установит зависимости, прогонит тесты, применит D1 migrations к `velocity-apex-db` и выполнит `wrangler deploy`.
