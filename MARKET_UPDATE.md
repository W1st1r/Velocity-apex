# Velocity Apex — Player Market Update

## Что добавлено

- Рынок разблокирован в магазине.
- Разделы: **Машины**, **Покупки**, **Продажи**, **История**.
- Игрок может выставить принадлежащую ему машину на продажу и указать цену.
- Другие игроки могут купить активное объявление.
- Игрок может создать запрос на покупку конкретной машины со своей ценой.
- Другой владелец этой машины может выполнить запрос.
- Для заявок на покупку кредиты резервируются до выполнения или отмены.
- Для объявлений на продажу машина хранится в рыночном escrow до продажи или отмены.
- Тюнинг машины сохраняется и переходит новому владельцу.
- Собственные объявления и заявки можно отменять с автоматическим возвратом машины/кредитов.
- История хранит завершённые покупки и продажи.
- Интерфейс рынка адаптирован в первую очередь под телефон и iPhone landscape.
- Добавлен поиск по машине/игроку и ручное обновление рынка.

## Исправление управления

- В режиме **РУЛЬ** редактор раскладки теперь показывает виртуальный руль.
- Руль можно перемещать по экрану и менять его размер.
- Старые сохранённые раскладки совместимы с новой версией.

## База данных

Добавлена миграция:

`migrations/0008_market.sql`

Сервер также создаёт отсутствующие таблицы рынка при первом обращении, но для production рекомендуется применить миграцию перед deploy.

## Обновление через Cloudflare Wrangler

```bash
npm install
npx wrangler d1 migrations apply velocity-apex-db --remote
npm test
npm run deploy
```
