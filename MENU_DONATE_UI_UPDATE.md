# Velocity Apex — Main Menu & Donate UI update

## Что изменено
- Главное меню собрано в стабильную сетку для iPhone/PWA: режимы слева, быстрые разделы справа, статистика снизу.
- Быстрые кнопки сгруппированы в понятном порядке: Магазин → Гараж → Донат → Аккаунт → Друзья → Клан → Промокод → Поддержка → Настройки.
- Убраны конфликтующие растяжения `Клан`/`Настройки` финальным override-слоем.
- Донат выделен отдельной премиальной карточкой в главном меню.
- Экран пополнения CR полностью переработан: яркие пакеты, подсветка выбранного пакета, аккуратные статусы, улучшенные кнопки оплаты, история платежей.
- Технический callback скрыт из обычного интерфейса игрока, сама серверная логика ЮMoney не менялась.
- Добавлены адаптивные правила для iPhone landscape, очень низких экранов и portrait.
- Добавлена поддержка `prefers-reduced-motion`.

## Серверная логика
Логика платежей, webhook, начисление CR, защита от повторного `operation_id` и API не изменялись.
