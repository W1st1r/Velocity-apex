# Velocity APEX V40 — Drift Megapark + Mini-game Mobile HUD

## Изменения

- В свободном онлайн-режиме оставлена одна Drift Zone: **HARBOR DRIFT MEGAPARK**.
- Площадка перенесена/расширена в левом нижнем секторе карты: 1000×740 игровых единиц против 440×350 ранее (примерно в 4.8 раза больше по площади).
- Серверная зона дрифта синхронизирована с клиентом: центр 670×2310, радиус 320.
- Удалены Industrial Drift и Parking Drift как отдельные Drift Battle зоны.
- Нижние западные дороги переразведены вокруг большой дрифт-площадки, чтобы трасса не пересекала зону.
- Сделаны отдельные видимые ENTRY / EXIT полосы без невидимого барьера.
- Добавлена защита от старых сохранённых Drift Battle с удалёнными zoneId после обновления Durable Object.
- Все HUD мини-игр в активном матче переведены в компактный формат.
- На iPhone/iPad landscape HUD мини-игр уменьшен до компактной полосы; показываются максимум две строки рейтинга.
- Экран выбора мини-игры в landscape тоже уменьшен.
- Камера мини-футбола / Checkpoint Rush / Hot Potato на телефоне отдалена примерно на 18%, чтобы больше поля попадало в кадр.
- Cache-bust CSS/free-city/freeroam обновлён до `20260919-v40`.

## Проверка

- `npm test` — пройден.
- `npm run test:map` — пройден.
- Геометрия дорог, въезды/выезды, кольцо Drift Zone и связность карты проверены тестами.
