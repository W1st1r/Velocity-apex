# Velocity Apex — Mobile UI V4

Обновление оптимизирует главные и новые интерфейсы под телефон, прежде всего под landscape iPhone/Android.

## Что изменено

- Главное меню переделано в компактный dashboard: слева крупные кнопки игры, справа быстрый доступ к гаражу, магазину, клану, друзьям, аккаунту, поддержке, Admin Panel и настройкам.
- Добавлены safe-area отступы для устройств с Dynamic Island / вырезами / home indicator.
- Унифицированы размеры карточек, скролл и touch-target кнопок во всех основных меню.
- Поля ввода на мобильных используют размер, не провоцирующий нежелательный Safari zoom при фокусе.
- Support/Admin Panel стал компактнее: фиксированные вкладки, более плотные карточки и адаптивные сетки статистики.
- Owner/ROOT интерфейс адаптирован к телефону: горизонтальная навигация, уменьшено давление много-колоночных блоков.
- Market получил полноэкранный phone-layout, крупнее touch элементы и более удобные диалоги покупки/продажи.
- Crew и Tuning ограничены safe-area и высотой экрана; заголовки/вкладки остаются доступными при прокрутке.
- Account, Promo, Friends, Server Browser, Online, Setup, Shop, Garage, Settings, Pause и Results используют единый мобильный shell.
- Для коротких landscape-экранов добавлен отдельный breakpoint до 540px по высоте.

## Публикация

Из корня проекта:

```bash
npm install
npm test
npx wrangler d1 migrations apply velocity-apex-db --remote
npx wrangler deploy
```

Если миграция `0010_admin_system.sql` уже была применена ранее, Wrangler просто не будет применять её повторно.

## Проверка после deploy

1. Открыть URL, который напечатает `npx wrangler deploy`.
2. Полностью перезагрузить страницу / PWA.
3. Проверить главное меню в landscape.
4. Открыть: Магазин → Рынок, Гараж → Тюнинг, Клан, Поддержка, Admin Panel (для администратора), Owner Panel.
