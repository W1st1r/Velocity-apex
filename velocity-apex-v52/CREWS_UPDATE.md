## REP

Street REP ведётся на сервере с момента установки обновления, отдельно от EXP. До вступления REP накапливается только лично. Нельзя отправить произвольное количество REP с клиента.

| Источник | REP |
| --- | ---: |
| Подтверждённый драг | 20 |
| Подтверждённый финиш онлайн-заезда | 30 |
| Drift Battle: 1 / 2 / 3 место / участие | 60 / 46 / 36 / 23 |
| KOTH: 1 / 2 / 3 место / участие | 73 / 56 / 43 / 26 |
| 20 минут активной езды в свободном режиме | 10 |

Действуют существующие серверные требования активности и проверки финиша. Стоянка не приносит REP. Общий лимит — 500 REP на игрока в сутки, сброс в 00:00 UTC. Одно серверное событие засчитывается один раз. Вклад вышедшего игрока остаётся у прежнего клана; дальнейший вклад идёт в новый.

## Недельные выплаты

Неделя: воскресенье 18:00 UTC → следующее воскресенье 18:00 UTC (21:00 МСК). При равном REP выше клан с меньшим постоянным ID.

| Место | Лидер | Каждый подходящий участник |
| --- | ---: | ---: |
| 1 | 12 000 CR | 4 000 CR |
| 2–3 | 9 000 CR | 3 000 CR |
| 4–10 | 6 000 CR | 2 000 CR |
| Остальные | 3 000 CR | 1 000 CR |

Условия для каждого получателя, включая лидера: минимум 100 личного REP в этом клане за неделю, вступление минимум за 24 часа до конца недели, членство на момент расчёта. Сам клан должен набрать минимум 500 REP. Лидер получает одну выплату по колонке лидера. Недельный рейтинг начинается заново, общий REP сохраняется.

Выплаты производятся серверным Cron Trigger, включая офлайн-игроков. Cron запускается каждый час: в воскресенье в 18:00 UTC рассчитывает неделю, следующие запуски могут повторить расчёт после временного сбоя. Перед изменением состава тоже выполняется расчёт завершённых недель. Выплаты и запись об их завершении — одна транзакция D1: повторный запуск не удваивает деньги. Сохраняется существующий потолок баланса 999 999 999 CR.

## Обновление из GitHub Codespaces / терминала репозитория

Загрузите `Velocity-Apex-Crews-Profiles-Reports.zip` в корень репозитория. Команды для проекта из этого архива:

```bash
unzip -o Velocity-Apex-Crews-Profiles-Reports.zip -d .
npm install
npx wrangler d1 migrations apply DB --remote
npm run deploy
git add src public migrations tests package.json package-lock.json wrangler.jsonc CREWS_UPDATE.md
git commit -m "Add crews, weekly rewards, player profiles and reports"
git push
```

Нужен Node.js 22.13+ для SQLite-тестов. Развёртывание использует уже настроенный аккаунт Cloudflare. Если это отдельный тестовый сервер с другой конфигурацией, перед распаковкой сохраните его `wrangler.jsonc`; после распаковки перенесите свои `name`, `database_id` и остальные привязки, сохранив новый `triggers.crons: ["0 * * * *"]`. Применяйте миграции к базе именно этого сервера. Старые миграции повторно не применяются.

Новая миграция: `migrations/0009_crews_reports.sql`. Она добавляет таблицы и индексы, не удаляет аккаунты, машины или рынок. Cron должен быть развёрнут вместе с Worker — одной загрузки статических файлов недостаточно.

После обновления перезагрузите игру. Быстрая проверка: создать клан, вступить вторым аккаунтом, завершить активность, открыть профиль и отправить жалобу со скриншотом, просмотреть её через разблокированную панель владельца.
