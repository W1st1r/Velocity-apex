# Velocity Apex V68 — UI controls & Clan UX polish

## Что изменено

1. **Управление одиночным заездом**: круглые кнопки стрелок/GAS/BRAKE/HB оформлены в стиле кнопок Free Roam; сохранены ID кнопок, сенсорная логика и поддержка индивидуального расположения элементов (control-layout-custom). Корректируются только CSS/надпись ручника, не физика и не серверный онлайн-протокол.
2. **HUD обычной гонки**: непрозрачные тёмно-синие панели миникарты, позиции, круга, времени, скорости, очков и паузы. Сохранена семантическая раскраска важных состояний и текущие размеры на разных iPhone.
3. **Друзья/аккаунт/промокод**: центровка контейнеров, ограничение выхода заголовков, safe-area и адаптивные поля. «АКТИВИРОВАТЬ» больше не переносится на две строки даже на узких экранах.
4. **Кланы**: по кнопке «ПРОСМОТР» открывается карточка любого клана с тегом, именем лидера (кнопка открывает профиль), типом, числом участников, REP за неделю, REP за всё время, датой основания. Если игрок без клана, внутри доступны вступление или отправка заявки. Возврат в рейтинг работает без перезагрузки. Карточка прокручивается с начала.
5. **Числа «26 всего», «144 всего»**: на самом деле это суммарный Street REP клана за всё время; текст теперь явно пишет «Всего: ... REP», отдельно «Неделя: ... REP».
6. **Теги новых кланов**: только 2–3 символа A–Z/0–9, одинаково проверяются формой и сервером. Уже существующие теги до 5 символов не ломаются: разрешено сохранить их без изменения, при замене новый тег должен быть не длиннее 3 символов.
7. **Кэш/версия**: обновлены URL файла оформления, скрипта кланов, экранная версия и `/version.json`.

## Что проверено

- `npm run test:v68` — успешно: отдельные проверки интерфейса, логики кланов, V66 и V67.
- `npm test` — успешно, включая авторизацию, платежи, гонки, экономики, онлайн-системы, панель управления, гараж и Upgrade.
- Chromium CSS-макеты на 932×430, 844×390 и 667×375: нет общего горизонтального переполнения для HUD, кнопок, друзей, аккаунта и промокодов.
- Chromium сценарии списка кланов, просмотра лидера и REP, возвращения из карточки: прошли на 932×430 и 667×375. Раздел кланов требует вертикального скролла на коротких экранах — это ожидаемо.
- Синтаксис файлов JS и CSS, наличие ассетов, целостность ZIP перед публикацией.

## Ограничения

Браузерные проверки проводились на эмуляции размеров iPhone; реальная Safari/PWA на iPhone и взаимодействие нескольких реальных игроков после деплоя требуют дополнительного ручного тестирования. Деплой **не выполнялся в этом окружении**, он делается пользовательским скриптом в GitHub Codespaces. База пользователей и цены/физика/шансы Upgrade не изменены.

## Обновление

1. Загрузить на `https://github.com/W1st1r/Velocity-apex/upload/main` два файла: ZIP V68 и скрипт `Velocity-Apex-V68-One-Paste-Deploy.sh`; нажать Commit changes.
2. В Codespaces выполнить: `cd /workspaces/Velocity-apex && git fetch origin main && git show origin/main:Velocity-Apex-V68-One-Paste-Deploy.sh | bash`
3. Дождаться финального сообщения. Скрипт отдельно проверяет публикацию Cloudflare и `/version.json` живого сайта. При ошибке показывает этап и последние сообщения, без ложного «успеха».
