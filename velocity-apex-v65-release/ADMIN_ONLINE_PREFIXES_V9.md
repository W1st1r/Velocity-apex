# Velocity Apex — V9 Admin Online Prefixes

Добавлены серверно подтверждённые префиксы для всех пяти уровней администрации во всех основных онлайн-интерфейсах.

## Префиксы и цвета

- **Helper** — бирюзовый / cyan-teal (`#0E7C76`, светлая обводка `#47E3D2`)
- **Moder** — синий (`#145FA8`, обводка `#66B8FF`)
- **St.Moder** — фиолетовый (`#6540A8`, обводка `#B28AFF`)
- **Admin** — янтарно-оранжевый (`#A35D12`, обводка `#FFC166`)
- **Curator** — золотой (`#8D7410`, обводка `#FFE26E`)

Красный и розовый не используются, потому что они зарезервированы под OWNER и QUEEN.

## Где показываются

- Free Roam: над машиной рядом с ником;
- Free Roam: основной чат;
- Free Roam: превью чата;
- Free Roam: результаты Live Events;
- обычный Online: список игроков комнаты;
- обычный Online: таблица результатов.

## Защита

Префикс нельзя подделать с клиента: `adminLevel` определяется сервером по активной записи в `staff_admins`. Сервер также периодически обновляет публичную роль игрока, поэтому повышение/понижение начинает отображаться без повторного входа после ближайшей синхронизации. OWNER и QUEEN имеют приоритет над административным префиксом.

## Обновление

```bash
cd /workspaces/Velocity-apex
unzip -o Velocity-Apex-Admin-Online-Prefixes-V9.zip -d .
npm install
npm test
npx wrangler deploy
```

D1-миграция не требуется.
