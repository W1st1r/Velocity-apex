- Перенесён только экранный anchor Coastal Ridge; owner, доходность, защита, influence и capture logic не менялись.

## BLOCKED: обязательная визуальная проверка

Playwright package найден, но Chromium/Firefox/WebKit executables отсутствуют по ожидаемым cache paths; `command -v` не нашёл системный browser. Доступный CUA Chrome не смог достичь локального приложения `http://127.0.0.1:32847/` (`net::ERR_CONNECTION_REFUSED`), так как его browser process изолирован от workspace loopback. Локальный static server после проверки остановлен.

Поэтому не выполнен ни один screenshot/browser check: главное меню, гараж, гонка, кланы/казна/3×3, войны, карта восьми районов, сезоны/рейтинг/задания, кейсы, чат/друзья и баг-репорты. Не проверены iPhone 13/14/15/17 landscape размеры, safe areas, overflow, taps, перекрытия, прокрутка и browser console. Эта обязательная проверка отсутствует, поэтому нельзя выставить PASS или CONDITIONAL.
