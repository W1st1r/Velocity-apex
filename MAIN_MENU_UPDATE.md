# Velocity Apex — Main Menu V3

Обновление главного меню без изменения игровой логики.

## Что изменено
- Главное меню разделено на понятные блоки: режим игры, гараж/профиль, статистика.
- Основные действия «Играть рядом» и «Онлайн» стали визуально главными.
- Магазин, гараж, аккаунт, друзья, промокод и настройки собраны в сетку 3×2.
- Для каждого раздела добавлена собственная иконка и вторичная подпись.
- Длинные ники, суммы и статусы используют `text-overflow: ellipsis` и не ломают карточки.
- Добавлены отдельные размеры для низких экранов iPhone в landscape.
- На экстремально узких landscape-экранах сетка безопасно перестраивается в 2 колонки.
- Сохранены все прежние DOM ID, поэтому существующая JS-логика кнопок не менялась.
- Версия CSS обновлена для сброса браузерного/PWA-кэша.
