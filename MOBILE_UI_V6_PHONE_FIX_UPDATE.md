# Velocity Apex — Mobile UI V6 Phone Fix

Дата: 16.09.2026

## Что исправлено

### Главное меню
- панель теперь всегда центрируется внутри реального viewport телефона;
- добавлены жёсткие ограничения по ширине/высоте с учётом safe-area iPhone;
- устранён горизонтальный выезд карточки и кнопок за экран;
- быстрый доступ стабильно работает в 2 колонки в landscape;
- «КЛАН» остаётся акцентной карточкой на всю ширину блока;
- если Admin Panel скрыта, «НАСТРОЙКИ» автоматически занимает всю последнюю строку, чтобы сетка не выглядела оборванной;
- режимы игры, статистика и SOUND больше не растягивают панель;
- длинные значения CR, ники и подписи обрезаются внутри своих карточек, а не расширяют меню.

### Поддержка / Admin Panel
- кнопка «НАЗАД» больше не растягивается на половину/всю шапку;
- шапка стала компактной и безопасной для iPhone landscape;
- 4 вкладки поддержки укладываются в одну ровную строку на обычном landscape-телефоне;
- на узких/портретных экранах вкладки превращаются в горизонтально прокручиваемую ленту;
- форма жалобы в landscape перестроена в 2 колонки: игрок + категория, описание на всю ширину, доказательства + отправка;
- уменьшены лишние вертикальные отступы и высота textarea;
- поля остаются 16px, чтобы Safari не делал нежелательный zoom при фокусе;
- контент прокручивается только внутри панели и не залезает под Home Indicator.

### Остальные новые меню
Добавлено дополнительное ограничение overflow/min-width для:
- Owner/Admin management;
- Market;
- Crew;
- Tuning;
- карточек жалоб/отчётов/администраторов;
- длинных никнеймов и текста;
- групп административных действий.

Названия рангов сохранены:
1. Helper
2. Moder
3. St.Moder
4. Admin
5. Curator

## Cache bust
Используются новые версии:
- `style.css?v=20260916-mobile6`
- `mobile-ui.css?v=20260916-mobile6`
- `admin-system.css?v=20260916-admin4`
- `admin-system.js?v=20260916-admin4`

Это заставляет Safari/Cloudflare взять новые файлы интерфейса вместо старого mobile5/admin3 из кэша.

## Проверка
В проект добавлен `tests/mobile_ui_v6_smoke.js`.
Полный `npm test` проходит успешно, включая администрацию, рынок, кланы, Free Roam, гараж, онлайн и текущие игровые системы.

## Обновление через GitHub Codespaces
Положите ZIP в `/workspaces/Velocity-apex`, затем:

```bash
cd /workspaces/Velocity-apex
unzip -o Velocity-Apex-Mobile-UI-V6-Phone-Fix.zip -d .
npm install
npm test
npx wrangler deploy
```

Миграцию D1 для этого обновления запускать не требуется: схема базы данных не менялась.
