# Velocity Apex V65 — Race Control / Upgrade

Готовое обновление для текущего проекта V64: игровые данные, авторизация, онлайн-режим, каталог и экономика V63 остаются в исходной конфигурации, кроме согласованной вероятностной модели Upgrade.

## Главное меню №4: Race Control
- Трёхзонная компоновка: компактная боковая панель / режимы / выбранный автомобиль, баланс и настройки.
- Два основных действия: одиночная игра и онлайн. Гараж, магазин, друзья, профиль доступны с одного касания.
- Дополнительные пункты (клан, промокод, поддержка, админка, звук) спрятаны под «ЕЩЁ»; старые ID кнопок сохранены.
- Адаптация под горизонтальные экраны iPhone с учётом safe-area, а также резервная портретная компоновка.
- Выбранная купленная машина отображается через существующий игровой ресурс. Для стартовой APEX LIME добавлена отдельная SVG-иллюстрация.
- Дополнительные данные меню: лучшие результаты, текущий CR, уровень аккаунта.

## Новая серверная экономика Upgrade

`шанс = min(85%, стоимость_ставки / стоимость_цели × коэффициент_аккаунта)`

| Завершённых попыток | Уровень | Коэффициент |
|---|---|---|
| 0–4 | любой | 98% |
| 5–19 | любой | 94% |
| 20+ | 0–29 | 90% |
| 20+ | 30–59 | 91% |
| 20+ | 60+ | 92% |

Завершённые попытки берутся **из серверной базы D1** (предшествующие Upgrade V64 учитываются). Уровень также проверяется на сервере. Серии поражений/побед не дают тайного изменения коэффициента. В редком случае ограничения 85% фактическая ожидаемая доходность может быть ниже указанного коэффициента.

Зелёный сектор всегда показывает **реальную вероятность**, а не увеличенную декоративно. Результат выбирает сервер до анимации, клиент рисует стрелку строго в правильном секторе. Примерно раз в 2–4 завершённых вращения стрелка останавливается в пределах ~3 CSS-пикселей от границы сектора. При попадании в зелёную область всегда выдаётся награда; при красной ставка теряется. Победа не гарантируется и не может быть определена по анимации.

## Проверки
- `npm test` — стандартные игровые автоматические тесты (пройдено при сборке).
- `npm run test:v65` — 2000+ проверок расчёта, геометрии «почти попал», наличия элементов, старой защиты от дублирующих попыток.
- Проверка геометрии браузером для размеров iPhone 932×430, 844×390, 667×375, 740×360 и портретного 393×852.

**Ограничение:** живой вход в Cloudflare, реальные D1-данные и задержки разных устройств здесь недоступны, поэтому после деплоя рекомендуется проверить одну ставку на тестовом аккаунте, онлайн-режим и навигацию.
