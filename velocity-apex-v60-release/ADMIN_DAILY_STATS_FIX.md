# APEX — Admin daily statistics fix

Исправлена статистика в OWNER PANEL → Администраторы.

- Дневной период: 00:00–00:00 по времени проекта UTC+3.
- Онлайн администратора считается во время обычного нахождения в игре, а не только при открытой админ-панели.
- Вопросы за день считаются по фактически закрытым обращениям типа `question`.
- Жалобы за день считаются по фактически обработанным обращениям игроков (`resolved` и `rejected`).
- Приглашённые за день считаются по подтверждённым рефералам, созданным в текущие сутки.
- В 00:00 автоматически начинается новый дневной период; история прошлых дней остаётся в БД.
- OWNER PANEL автоматически обновляет статистику раз в 30 секунд, пока вкладка видима.
