# Velocity Apex V67 — Racing AI & Physics

Дата выпуска: 13 октября 2026 года. Основа: V66 Race Control Blue, без изменения серверных аккаунтов, экономики, Upgrade и сетевого протокола.

## Исправления и новая логика

1. **Старт с последней позиции.** В `public/js/game.js` игрок создаётся последним из `bots+1` участников и ставится на 76 игровых единиц позади последнего ряда. Работает при любом разрешённом количестве ботов; в карьере, где нет соперников, игрок один.
2. **Каждому из 13 ботов — собственные параметры.** `R.botSkillProfile` выдаёт детерминированные характеристики машины: ускорение, максимальную скорость, торможение, чувствительность руля, сцепление, гоночный темп, точность торможения и обгоны. Сложность масштабирует уровень соперников. На экстремальной сложности разброс максимальной скорости ~98,3–110,8% от выбранной машины; это не мгновенная помощь отстающим, а реальные характеристики на весь заезд.
3. **Оптимальные линии.** Сохранён и использован существующий полный планировщик трасс: анализ кривизны, предвычисление траекторий/апексов, скоростной профиль с учётом сцепления и тормозного пути. Усовершенствованы траектория экстремальных ботов на внутреннем поребрике и допуски безопасных проездов. Физика не позволяет считать траву асфальтом.
4. **Позднее обоснованное торможение и плотная борьба.** Снижен лишний штраф скорости в плотной группе; дистанция до замедляющегося соперника теперь учитывает возможность реально открытого коридора для обгона. При сложном S-повороте и в параллельном движении боты перестраиваются в пределах ширины дороги.
5. **Более ощутимая физика.** Сильнее снижается максимальная угловая скорость руления при приближении к максимальной скорости, управляемость в среднем диапазоне остаётся уверенной. Модель сцепления и торможения общая для игроков и ботов. Обособленная дрифт-физика не изменена.
6. **Кэш и версия.** Добавлена V67 в заголовок/главное меню, обновлены URL изменённых JS-файлов, `/version.json` сообщает V67.

## Известные ограничения

- Тестовый AI использует заранее оптимизированный по геометрии алгоритм и моделирование поведения, **не нейросеть**. Создание новой нейросети для такого браузерного симулятора не требуется и могло бы ухудшить FPS на iPhone.
- Математически нельзя гарантировать место игрока 3–4 в каждом заезде: оно зависит от выбранной машины, тюнинга, качества управления, длины гонки и соперников.
- В очень плотной группе на узких поворотах контакты машин **возможны**, хотя все тестовые гонщики финишировали и не били барьеры.
- Изменения затрагивают все одиночные заезды с ботами; общая физика управления применяется и в других режимах, поэтому проверка живой онлайн-игры на нескольких iPhone всё ещё нужна после обновления.

## Публикация

Загрузить в корень репозитория в GitHub `main` два файла: `Velocity-Apex-Racing-AI-Physics-V67.zip` и `Velocity-Apex-V67-One-Paste-Deploy.sh`. Нажать `Commit changes`, затем выполнить в Codespaces:

```bash
cd /workspaces/Velocity-apex && git fetch origin main && git show origin/main:Velocity-Apex-V67-One-Paste-Deploy.sh | bash
```

Скрипт сверяет SHA256 архива, устанавливает V67 в чистый Git worktree, запускает `npm run test:v67` и `npm run test:v66`, отправляет коммит в GitHub, публикует через Wrangler, затем проверяет `/version.json` на живом сайте. На ошибке печатает этап и последние сообщения журнала. **Не запускает операции с D1 или сброс аккаунтов.**
