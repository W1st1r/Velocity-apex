# Velocity Apex V66 — Race Control Blue / Unified UI / Audit

**База:** подтверждённый исходный архив V65 `Velocity-Apex-Race-Control-V65-CORRECT-20261013.zip`.  
**Дата сборки:** 13.10.2026.  
**Установка:** архив содержит полный корень проекта (`public/`, `src/`, `tests/`, `wrangler.jsonc` и другие файлы), не вложенную папку проекта.

## Реализовано

1. **Единый дизайн Race Control Blue.** Синие и тёмно-голубые поверхности, акценты, границы, элементы выбора, информационные блоки. Переработаны семь наследуемых CSS-файлов, 902 стилевых правила с остатками зелёной UI-палитры. Добавлен финальный слой `public/css/unified-blue-v66.css`.
2. **Согласованные экраны:** старт/авторизация, основное меню, одиночный заезд, карьера, гараж/Upgrade/тюнинг, магазин/рынок/кейсы, онлайн-комнаты, настройки, аккаунты, друзья, пополнение CR, промокоды, реферальная программа, административные и клановые окна. Сохранены текущие ID, события и переходы.
3. **Компоновка iPhone:** безопасные зоны, ограничения высоты карточек, прокрутка при нехватке места, отображение длинных значений, фокус клавиатуры, текст в полях. Браузерный smoke-тест: 51/51 проверок на 932×430, 844×390 и 667×375. Эти тесты проверяют структуру и CSS, а не серверные переходы после авторизации.
4. **Исправлено лишнее обновление скрытого меню:** вместо постоянного таймера 1,4 с — моментальная реакция на открытие/возврат и фоновое обновление только открытого меню с периодом 12 с.
5. **Исправлены доступные подписи:** 6 элементов чата и админки получили `aria-label`.
6. **Кэш и версия:** CSS-ресурсы получают `theme=v66`, новая тема загружается последней; обновлены оттенок Safari/PWA, сезон V66 и статический файл `/version.json` для проверки реально опубликованной сборки.
7. **Не трогали серверную экономику, базу, авторизацию, физику и сетевой протокол.** Сохранены реальные цвета машин, редкость предметов, цветные ранги администрации и реальные зелёный/красный сектора Upgrade.

## Известные ограничения аудита

- Проверены исходники, контракты API и автономные тесты, но **не проводилось полномасштабного нагрузочного тестирования Cloudflare/D1 с реальными пользователями**, не выполнялись платные транзакции и не менялись данные реальных аккаунтов.
- Карты и внешний вид машин намеренно не перекрашиваются в синий: речь только о **единстве интерфейсов**.
- Прежние GitHub Actions могут не публиковать сайт без secrets Cloudflare, поэтому для V66 предусмотрена **прямая публикация через Wrangler из Codespaces** и проверка `/version.json` на живом URL.

## Как проверить опубликованную версию

Откройте `https://velocity-apex.maximmanzha20.workers.dev/version.json`. Поле `version` должно быть `V66`. Затем откройте игру в приватном Safari, при установленном PWA при необходимости перезапустите приложение.
