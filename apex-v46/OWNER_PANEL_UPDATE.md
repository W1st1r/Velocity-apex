# Панель владельца

Доступ: аккаунт @w1st1r, через настройки. Пароль панели сохранён.

## Что добавлено

- Название «Панель владельца» и общий онлайн сверху. Онлайн обновляется каждые 15 секунд. Аккаунты считаются без повторного учёта вкладок; свободные серверы дополнительно проверяются по соединениям. После закрытия игры статус может оставаться онлайн до 45 секунд.
- Аккаунты → игрок → «Общее»: регистрация, вход, последняя активность, онлайн/офлайн, место в игре, свободный сервер, время, баланс, машины и уровни улучшений, результаты, друзья, промокоды, пригласитель, наказания и последние 200 административных событий.
- Кик из свободного режима закрывает соединение и удаляет сессию на сервере. Старый токен больше не подходит. Игрок может подключиться заново; для запрета повторного входа используется блокировка.
- Машины: цена, категория, доступность, LIMITED, скорость, ускорение, торможение, поворот, скольжение, прирост улучшений и множители их цены.
- Персональные параметры хранятся на сервере отдельно от обычного сохранения. Они заменяют итоговые характеристики после улучшений и не передаются ботам или другим аккаунтам.
- Выдача выбранному игроку или себе. Для другого получателя откройте профиль и нажмите «Настроить машину игроку».
- «Выдать всем» сохраняет постоянное правило: существующие офлайн-игроки и будущие аккаунты получают машину при входе. Повторная выдача не создаёт дубликатов. Облачный гараж обновляется штатной синхронизацией.
- «Технические работы» закрывает обычным игрокам API входа, регистрации и игры. Свободные серверы отключают их сразу; уже открытые онлайн-соединения проверяются не реже одного раза в 10 секунд при поступлении сообщений. Открытая игра показывает заглушку при ближайшем опросе, обычно до 15 секунд. @w1st1r остаётся в игре.
- Для телефона: одна колонка редактора, крупные кнопки, шрифт полей 16 px, прокрутка панели, поддержка safe area и высоты экрана Safari.

## Как изменить скорость только себе

1. Панель владельца → Машины → выберите автомобиль.
2. Получатель → «Я», затем «Выдать получателю».
3. Укажите скорость, ускорение, торможение и другие значения в полях выше.
4. Нажмите «Применить характеристики получателю».
5. Выберите машину в гараже и начните новый заезд / войдите на свободный сервер.

Кнопка «Сохранить для всех игроков» меняет общие характеристики модели. Персональные параметры можно удалить отдельной кнопкой сброса. Новые параметры подхватываются при следующем выезде; текущая гонка не перенастраивается посреди движения.

## Важные особенности данных

- Время и количество заездов начинают учитываться с этого обновления. Прошлые события, которых не было в базе, восстановить нельзя. Существующие лучшие круги и счёт берутся из сохранения.
- Завершённый драг и онлайн-заезд записывает сервер с защитой от повторного учёта. Одиночные заезды сообщает клиент. Прерванные заезды не считаются завершёнными.
- Время — активное время приложения, а не время с даты регистрации. Обычная скрытая вкладка не отправляет heartbeat.
- LIMITED — визуальная отметка. Для ограничения продажи включите «Временно недоступна»; отдельного лимита тиража в этой версии нет.
- Отключённая машина остаётся в коллекции, но обычный игрок не может выбрать её для нового выезда. Владелец может тестировать её. Базовую apexLime отключить нельзя.
- Скорость, ускорение и торможение допускают значения от 1 до 100000; поворот — 0.01–100; скольжение — 0.05–20. Бесконечность и некорректные числа сервер отклоняет. Экстремальные значения не гарантируют нормальную управляемость на небольшой карте.
- Система не заменяет клиентскую физику полноценной серверной симуляцией или античитом. Она сохраняет архитектуру исходной игры.

## Обновление из терминала GitHub Codespaces

Загрузите Velocity-Apex-Owner-Panel.zip в корень репозитория. Выполняйте команды из папки, где находятся package.json и wrangler.jsonc:

```bash
unzip -o Velocity-Apex-Owner-Panel.zip -d .
npm install
npx wrangler d1 migrations apply velocity-apex-db --remote
npm run deploy
```

Миграция 0006 добавляет таблицы, не удаляя аккаунты и сохранения. Для фиксации исходников:

```bash
git add src public migrations tests package.json OWNER_PANEL_UPDATE.md OWNER_PANEL_TEST_REPORT.md
git commit -m "Add owner panel, player profiles and car tuning"
git push
```

После обновления перезагрузите игру на телефоне, включая ярлык с домашнего экрана, если он использовался.

## Проверки

`npm test` запускает прежние тесты игры и новый `tests/owner_panel_test.mjs` (требуется Node 22.13+ с node:sqlite). Сам Worker продолжает использовать Cloudflare D1.

Браузерная проверка мобильного отображения в этой среде недоступна: удалённый браузер отказался открывать локальный адрес. Реальный Safari/iPhone и живой Cloudflare не тестировались.
