# APEX BAY — новая карта свободного режима

Встроена в игру из приложенного архива. Одиночные гонки, аккаунты, гараж, чат и друзья используют прежнюю реализацию.

## Что изменилось

- Светлый прибрежный город 4200 × 3000 игровых единиц: озёрный серпантин, набережная, центральный парк с фонтаном, жилые кварталы, деловой центр, порт и аэропорт.
- 125 зданий: черепичные крыши, солнечные панели, промышленные корпуса, крыши офисов с вентиляцией. 262 дерева, дворы, кафе, спортплощадка и портовые детали.
- Широкие связанные дороги, пешеходные переходы и размеченные площадки. Геометрия изображения и проезда общая; автомобиль не проезжает через здания и озеро.
- Полностью открытая зона дрифта. Координаты сетевых активностей и старта drag сохранены.
- Карта без искажения пропорций, масштабирование кнопками +/− и колёсиком, перетаскивание при приближении, кнопка «Весь город». Метка привязывается к ближайшему проезду и удаляется кнопкой «Убрать метку». Линия к метке показывает направление, а не пошаговую навигацию.
- Статичный город рисуется по частям с ограниченным кешем; карта обновляется только при открытой панели. Внешние изображения и загрузки для нового города не нужны.

В файле APEX-BAY-PREVIEW.png — обзор, полученный непосредственно из кода нового города.

## Обновление существующего проекта

Распакуйте файлы поверх своей рабочей копии проекта, сохранив собственные настройки Cloudflare в wrangler.jsonc, если они отличаются. В терминале из каталога проекта:

```bash
npm install
npm run test:map
npx wrangler deploy
```

Новые миграции базы данных для этой карты не требуются. После публикации полностью перезагрузите страницу игры. Адреса изменённых скриптов и CSS получили новую версию для обновления кеша.

## Проверка

Успешно выполнены:

- `npm run test:map`: связность дорог, доступность старта и зон активностей, свободная окружность дрифта, отсутствие зданий и крон на дороге, безопасная привязка меток; существующие проверки свободного режима и управления.
- `online_protocol_test.mjs`, `online_network_test.js`, `online_room_test.mjs`: протокол, интерполяция и комнаты, включая сценарий ставок.
- Интеграционный стенд с Canvas и имитацией DOM: вход на сервер, кадры игры, увеличение карты, перетаскивание без случайной метки, установка/снятие метки, изменение размеров холста для 393 × 852 и 844 × 390, движение и выход.
- Визуально просмотрены изображения из настоящего рендера города, включая стыки кешированных частей.

Полный `npm test` останавливается на существующем `garage_visual_smoke.js`: тест требует старую строку `style.css?v=20260915-012`, которой уже нет в исходном приложенном архиве. Этот тест не исправлялся в рамках карты.

Реальный браузер и физический iPhone в этой среде недоступны. Проверка холстов и обработчиков не заменяет окончательную проверку интерфейса и производительности на устройстве; живое подключение к опубликованному серверу не проверялось.
