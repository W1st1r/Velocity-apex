# Velocity Apex — MEDIA V51 Mobile + Racing Events

## Что изменено

### 1. MEDIA Event полностью оптимизирован под телефон
- Экран создания MEDIA Event переработан в компактные секции вместо одной широкой строки.
- Добавлен отдельный мобильный layout для iPhone/iPad в landscape при ширине до 980px и небольшой высоте экрана.
- Поля автоматически перестраиваются: 3 колонки в landscape, 2 в portrait и 1 на самых узких экранах.
- Кнопки действий закреплены снизу внутри прокручиваемой панели, поэтому «Назад» и «Создать Event» не теряются за краем экрана.
- Кнопки Online Rooms больше не обрезают подписи «Создать комнату / Войти по коду / Создать MEDIA Event».
- Учтены safe-area и мобильный скролл.

### 2. MEDIA Event теперь поддерживает полноценные гонки
В дополнение к существующим мини-играм организатор может выбрать формат **ТРАССА / ГОНКА**.

Поддерживаются все текущие трассы проекта:
- обычные гоночные трассы;
- drift-трассы.

Настройки гоночного Event:
- трасса;
- обычная гонка или drift;
- количество кругов (для обычной гонки);
- минимум и максимум участников;
- столкновения;
- призовой фонд;
- доступ;
- организатор: участник или наблюдатель.

MEDIA Race использует существующий серверный движок Online Rooms и не дублирует отдельную физику гонок.

### 3. Spectator для гоночных трасс
Организатор MEDIA может создать Race Event как **НАБЛЮДАТЕЛЬ**.

В этом режиме:
- организатор не занимает слот гонщика;
- не появляется автомобилем на трассе;
- не влияет на столкновения и результат;
- камера может показывать всю трассу сверху;
- можно переключаться между гонщиками «предыдущий / следующий»;
- можно скрыть HUD для записи ролика или трансляции.

### 4. Серверная безопасность гонок и наград
- MEDIA Race создаётся как отдельная серверная комната с кодом Event.
- Приз остаётся в существующем MEDIA escrow.
- Победитель определяется серверным Online Room/Durable Object.
- Выплата MEDIA-приза выполняется сервером один раз.
- Spectator не может отправлять READY, движение автомобиля или финиш.
- При отмене до старта и безопасных аварийных сценариях используется существующий возврат escrow.
- Обычные ставки Online Rooms для MEDIA Race отключены, чтобы не смешивать две экономики.

## Совместимость
- Обычные Online Rooms не изменены по логике ставок и матчей.
- Free Roam и существующие MEDIA mini-games продолжают использовать прежний движок.
- Новая D1-миграция для V51 не требуется: используется схема MEDIA из `0016_media_events.sql`.
