# Velocity Apex — приглашения и промокоды

## Что добавлено

### Система приглашений
- При регистрации игрок может указать ник пригласителя (необязательное поле).
- Если приглашение прошло серверную антифрод-проверку, пригласителю автоматически начисляется **1500 CR**.
- Награда начисляется только на сервере через D1/облачное сохранение.
- Регистрация нового игрока не блокируется, если приглашение выглядит подозрительно — просто не выдаётся реферальная награда.

### Защита от мультиаккаунтов
По умолчанию действуют ограничения:
- один зарегистрированный аккаунт может быть приглашён только один раз;
- нельзя пригласить самого себя;
- пригласитель должен существовать;
- пригласитель должен быть старше 24 часов (root/admin исключён);
- одинаковый device/install ID не получает повторные реферальные награды;
- совпадение устройства с пригласителем отклоняет бонус;
- совпадение сети с пригласителем отклоняет бонус, если сигнал регистрации пригласителя известен;
- не более 3 успешных приглашений с одной сети за 7 дней;
- не более 5 успешных приглашений одному пригласителю за 24 часа;
- не более 20 успешных приглашений одному пригласителю за 30 дней.

IP/устройство не сохраняются в таблицу рефералов в открытом виде: сервер хранит их хэши для антифрод-проверок.

Основные лимиты находятся в `src/auth.mjs` рядом с `REFERRAL_*` и могут быть изменены перед деплоем.

### Промокоды
Игрок вводит код в новом окне **ПРОМОКОД** в главном меню.

Промокод может выдавать:
- CR;
- машину;
- эффект;
- кейс и количество кейсов;
- комбинацию этих наград.

Для кода можно настроить:
- название/описание;
- общий лимит активаций (`0` = без лимита);
- срок действия в часах или днях (`0` = бессрочно);
- активен/выключен;
- состав награды.

Один аккаунт может активировать конкретный промокод только один раз. Проверка срока, лимита активаций и повторного использования выполняется сервером. Счётчик использования резервируется атомарно, чтобы два одновременных запроса не могли обойти лимит.

## Root → Промокоды
В root-панели добавлена вкладка **ПРОМОКОДЫ**:
- создать новый код;
- просмотреть все коды;
- видеть число использований и срок действия;
- редактировать код и награды;
- включать/выключать код.

Все операции root остаются за существующей admin/root авторизацией и записываются в audit log.

## База данных
Добавлена миграция:

`migrations/0005_referrals_promocodes.sql`

Перед боевым деплоем применить её к удалённой D1:

```bash
npx wrangler d1 migrations apply velocity-apex-db --remote
```

После этого деплой:

```bash
npm run deploy
```

Сервер также умеет лениво создать новые таблицы при первом обращении, но применение миграции перед деплоем остаётся правильным вариантом.
